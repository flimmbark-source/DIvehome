# Divehome

Prototype repository for the low-poly incremental game built around The Apparatus.

The first vertical slice establishes:

- a sparse, navigable White Space
- an interactable Apparatus
- a first-person tunnel combat round
- a single-shot weapon with manual reload
- enemies that damage the player once when reaching the interaction plane, then park there until destroyed

The room progression and furnishing systems are intentionally deferred until the base Apparatus round is validated.
